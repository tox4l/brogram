## Three likely failures

1. Restricted filesystem/network access interrupts scaffold or CLI installation:
   stay within permitted paths, report the exact failed command, and continue
   independent work. Missing logins never stop local work.
2. Current package or shadcn behavior differs from the plan: inspect installed
   READMEs/types or official documentation, make the smallest justified fix,
   and record actual versions and deviations in `docs/build-log.md`.
3. Copying the scaffold overwrites curated files or stages private material:
   exclude protected paths and generated Git history; compare preserved hashes
   and inspect ignore rules plus staged paths before committing.
