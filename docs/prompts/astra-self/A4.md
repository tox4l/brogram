## Likely failures

1. Hydration overwrites cached aggregates or trusts spoofed internal account headers. Overwrite headers in middleware, avoid a second profile select, retain saved aggregates while refreshing date-derived streaks with the server clock.
2. Async submissions, navigation, or stream partials duplicate agent calls, attempts, points, or leave a stale hint eligible. Use synchronous operation guards, lifecycle cancellation, durable retry checkpoints, and fake-timer/spy tests.
3. Chain cap or bank exhaustion opens the same pattern, publishes an unverified generated exercise, or leaks hidden answers. Consume closed, validate reference execution and verify response, strip reference data, hide hidden test details, and test all fallback paths.
